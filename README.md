# Skinbot

Canale di aggiornamento automatico di Skinbot. Versione 1.0.36 (2026-10-19).

Skin dal catalogo di Fortnite (griglia con le icone, niente export) e statue Riferimento giocatore: la skin vera di chi gioca, sempre perfetta. Nuovo tasto 'Prepara mappa + Riferimenti giocatore'. Avvio del bot molto piu' veloce.

Per installare: scarica ed esegui `Installa Skinbot.bat`.
